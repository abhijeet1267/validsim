CI for Robot Foundation Models

ValidSim runs a robot model checkpoint through thousands of simulated episodes under domain randomization and adversarial scenarios, then returns a scorecard you can gate a deploy on.

Automated Validation

Run robot checkpoints through rigorous simulation pipelines with automatic pass/fail gating based on quantitative metrics.

Fine-Grained Metrics

Track success rates, composite scores, and failure taxonomy across thousands of episodes with statistical significance testing.

🔄

Regression Detection

Compare runs automatically to detect regressions vs baseline with anomaly detection for failure-mode spikes.

🚦

Deployment Gates

Integrate with CI/CD pipelines using exit codes that automatically approve or block deployments based on validation results.

Quick Start

Use the CLI to start validating your robot models

$ validsim run --checkpoint my_model.pt --episodes 1000

# Check status
$ validsim status

# Get scorecard
$ validsim scorecard

# Gate deployment
$ validsim gate && echo "APPROVED" || echo "BLOCKED"
